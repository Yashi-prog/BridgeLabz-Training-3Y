Responsive Design Principles

Three Important Principles of Responsive Web Design

Fluid Layouts

Fluid layouts use flexible units like percentages to adjust the width of elements according to screen size. 


.container {
    width: 100%;
}

Flexible Media

Flexible media allows images and videos to resize according to the available screen space. 


img {
    max-width: 100%;
    height: auto;
}

Breakpoints

Breakpoints are screen sizes where the website layout changes using media queries. 


@media (max-width: 600px) {
    body {
        background: lightblue;
    }
}
