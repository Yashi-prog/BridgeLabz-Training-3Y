Responsive CSS Cheat Sheet

Important CSS Concepts and Examples

Filters

CSS filters are used to change the appearance of images.

filter: grayscale(100%);

Media Queries

Media queries apply different styles according to screen size.

@media (max-width: 700px)

Responsive Design

Responsive design makes websites adjust to different devices.

width: 100%;

Typography

Typography controls the appearance and size of text.

font-size: clamp(1rem, 4vw, 2rem);
