CSS Box-Sizing Comparison

Comparing content-box and border-box

Default: Content-Box

Content-Box

Width does not include padding and border.

With content-box, the specified width applies only to the content. Padding and borders are added outside the specified width.

Border-Box

Border-Box

Width includes padding and border.

With border-box, the specified width includes the content, padding, and border.
