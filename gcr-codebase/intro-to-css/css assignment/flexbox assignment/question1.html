Hover, focus, active and nth-child examples

:hover

Hover Over Me

The :hover pseudo-class applies styles when the mouse pointer is placed over an element.

:focus

The :focus pseudo-class applies styles when an element receives keyboard or input focus.

:active

The :active pseudo-class applies styles while an element is being activated or pressed.
